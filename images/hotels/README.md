Preview images for the "Where to Stay Before or After" section.
File names must match the `image` paths in `content.js`.

|-------------------------|------------------------------------|---------|

**Tips:**
- Cards crop to a 180 px tall strip (`object-fit: cover`, centred), so wide landscape
  shots work best. Very wide panoramic crops are fine — the sides get trimmed, so keep
  the subject near the centre.
- JPEG or WebP, compressed (e.g. [Squoosh](https://squoosh.app/)).
- Until a file is added, the card shows a neutral placeholder with the hotel name —
  nothing breaks, so you can add the photos whenever you like.
- Please use photos you have permission to reuse (ask the hotel, or take your own)
  rather than hotlinking from the hotels' own websites.
